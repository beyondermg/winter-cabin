# Winter Cabin

A dark, cozy winter theme for Claude Code's desktop and mobile apps. Behind your chat: a moving snowy night with snow falling in layers, a slowly waving aurora, twinkling stars and the odd shooting star, a full moon, and a log cabin with flickering windows, string lights and chimney smoke, plus a snowman and snowy pines.

It also sets midnight-blue colors with a warm firelight accent, gives your messages a snow cap with icicles, puts Claude's replies on frosted cards, and adds a quiet ambience (wind and a crackling fire) with soft bell cues. Press the speaker in the session's title bar to hear it.

The terminal and editors draw no backdrop, so the theme shows only in the apps.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install winter-cabin --marketplace beyondermg/winter-cabin
```

Answer `y` to add the marketplace, then pick the user scope so it loads in every session.

From a shell:

```bash
claude plugin install winter-cabin --marketplace beyondermg/winter-cabin
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `beyondermg/winter-cabin`, then Add plugin.
